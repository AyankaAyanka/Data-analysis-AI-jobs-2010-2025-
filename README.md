# AI Impact on Jobs (2010-2025)

## Project Overview
This project analyzes how artificial intelligence has influenced the global labor market between 2010 and 2025.

The analysis focuses on:
- job vacancy trends
- salary distribution
- automation risks
- geographic differences

## Tools
- Python (Pandas)
- Power BI
- Excel
- Power Point

## Key Insights
- AI-related job opportunities increased significantly after 2020
- Automation risks differ across professions
- Salary levels vary significantly between industries
